# Hermes 실행 어댑터

`config/agents.json`에서 Hermes 설치 위치, 작업별 모델, 추론 강도와 역할별 프로필을 읽는다. 역할 표시 이름은 `config/roles.json`에서 불러오며 현재 빌더·센티널·피니셔로 설정했다.

- 일반 대화·개발·보완: `gpt-5.6-terra`, 추론 강도 `xhigh`
- 설계·리뷰: `gpt-5.6-sol`, 추론 강도 `xhigh`
- 설계·리뷰: `hermes chat`의 승인 거부 모드로 실행
- 개발·보완: 사용자의 계획 승인 뒤에만 `--yolo` 쓰기 허용
- 모든 실행: 승인된 Git 저장소를 현재 폴더로 지정하고 시간 제한·취소를 적용
- OAuth 파일은 존재 여부만 확인하며 내용은 읽거나 로그에 남기지 않음

Hermes 출력과 프롬프트는 비밀값 제거 후 `artifacts/<실행-ID>/`에 보관한다.
