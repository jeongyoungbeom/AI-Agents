# 이전 실행기

이 폴더는 초기에 만든 명령형 텔레그램 실행기다. 새 모듈식 시스템과 섞이지 않도록 보존만 하며, 새 개발은 `D:\AI-Agents\app`에서 진행한다.

기존 진입 파일:

- `agent_pipeline.py`: 이전 개발·리뷰·보완 실행기
- `telegram_gateway.py`: `/task`, `/project` 방식의 이전 텔레그램 게이트웨이

새 시스템이 완성될 때까지 회귀 테스트 대상으로 유지한다.

실수로 새 시스템 대신 실행하지 않도록 기존 PowerShell 진입 파일은 `-AllowLegacy`를 명시해야만 동작한다.
